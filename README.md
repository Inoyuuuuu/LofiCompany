[thunderstore link](https://thunderstore.io/c/lethal-company/p/Inoyu/LofiCompany/)

# Content
**This mod adds company issued lofi music to brighten up your mood on rainy days!**\
If you land on a planet where it is raining and when it is afternoon, there is a random chance that lofi music will start to play.

The Lofi track played is randomly selected from 37 songs and does not repeat within a game session (unless all 37 songs have been played once). \
Lofi will not play if there is no one in the ship, and if all players leave the ship, the music will stop after a short period of time.\
The conditions for Lofi such as weather and time of day can be adjusted in the configurations, as can the random probability of playing Lofi music.

## Configs (these are synced with lobby-host's configs!)

| Config Title              | Value                | Description                                                                                    |
|---------------------------|----------------------|------------------------------------------------------------------------------------------------|
| weather types             | keywords             | Sets the weather types on which lofi can be played.                                            |
| day modes                 | keywords             | Sets the time of day on which lofi can be played.                                              |
| player leave ship timer   | in seconds           | If all players leave the shiproom, after this amount of seconds lofi music will stop playing.  |
| music volume              | values from 0.1 to 1 | The volume of the lofi music.                                                                  |
| attempts per hour         | integer              | How often the company will try to put on some lofi per hour.                                   |
| chance per attempt        | in percent           | The chance of actually playing music on each attempt.                                          |
| is lofi stop active       | true/false           | If enabled, stops music for the rest of the day if you turn off the speaker                    |
